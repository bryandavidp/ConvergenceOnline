## Orden de lectura recomendado para una IA

1. [`CLAUDE.md`](https://bryandavidp.github.io/ConvergenceOnline/CLAUDE.md) para entender el proyecto y sus reglas operativas.
2. [`ARCHITECTURE.md`](https://bryandavidp.github.io/ConvergenceOnline/docs/ARCHITECTURE.md) para localizar módulos y responsabilidades.
3. [`REQUIREMENTS.md`](https://bryandavidp.github.io/ConvergenceOnline/docs/REQUIREMENTS.md) para conocer el comportamiento esperado.
4. [`MIGRATION_SPEC.md`](https://bryandavidp.github.io/ConvergenceOnline/docs/MIGRATION_SPEC.md) para consultar reglas, datos y fórmulas exactas.
5. [`DESIGN_SYSTEM.md`](https://bryandavidp.github.io/ConvergenceOnline/docs/DESIGN_SYSTEM.md) para reproducir la interfaz visual.
6. El plan o inventario específico del sistema que se vaya a modificar.
