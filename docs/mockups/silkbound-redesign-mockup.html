Design system Silkbound

Sistema visual original para Convergence: fantasía subterránea, seda ritual, máscaras propias, capas de profundidad y controles táctiles compactos. La dirección evita assets, personajes, marcas y composición literal de obras existentes.

Reglas de dirección visual

  • Silueta primeroPersonajes, HUD y piezas deben leerse en negro, hueso o escarlata antes de añadir textura.
  • Profundidad por capasFondo desenfocado, medio narrativo, tablero nítido y primer plano oscuro para crear teatro 2D.
  • Luz cálida escasaEl dorado se reserva para recompensa, foco, objetivo y progreso relevante.
  • Arte propioProhibido usar logotipos, personajes, jefes, mapas, iconos o capturas de Team Cherry como assets finales.
  • Botones sobriosControles compactos, táctiles y con relieve; evitar tarjetas coloridas tipo arcade espacial.
  • MovimientoPartículas lentas, hilos tensándose, polvo, respiración de luz y sacudidas breves para impacto.
