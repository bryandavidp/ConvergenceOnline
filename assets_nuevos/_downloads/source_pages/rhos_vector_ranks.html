Vector Ranks

Tiered rank icons in a variety of colourways, all completely free.

Features

  • 📦 750+ individual assets.
  • 🎨 Outlined and non-outlined variants.
  • 🪩 Visual style consistent with all RhosGFX icon packs .
  • 🌳 Large (256px) and small (64px) sizes.
  • 📁 SVG and PNG8 formats, optimised for smaller file sizes.

Thanks for checking out my first free pack! I'm hoping this will help out a lot of people in the game dev space and beyond. It took a lot of hard work, and I've never done something like this before, so I'm pretty excited to see how it goes 😄

This pack contains 2 styles of ranks:

  1. v1 contains 12 ranks of increasing size and complexity. There's 3 styles - Diamond, Shield and Hexagon - and 10 colourways.
  2. v2 contains a smaller set of 7 icons in 8 colourways. These ones all have a consistent size, so they're easier to use as icons.

Hope you enjoy!!
